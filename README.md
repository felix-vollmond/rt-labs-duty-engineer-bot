# Телеграм-бот дежурного инженера АО «РТ Лабс»

## О программе

Этот телеграм-бот разработан в качестве задания по производственной практике
в университете для АО «РТ Лабс».

Идентификатор бота: `@RTLabsDutyEngineerBot`

## Команды

### 📊 Создать и заполнить БД

```console
python -m scripts.populate_db
```

### 🚀 Запуск

```console
docker-compose up --build -d
```

### ⏹️ Остановка

```console
docker-compose down
```
